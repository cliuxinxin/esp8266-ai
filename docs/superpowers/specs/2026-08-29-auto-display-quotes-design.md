# 自动显示配置与名人名言功能设计

日期：2026-08-29

## 目标

为 AI Mac 小屏幕增加可配置的自动显示系统，让用户决定哪些页面参与自动显示，并为定时页面分别设置出现间隔和单次显示时长。同时增加中英文混合的联网名人名言页面。

本次实现仅覆盖 macOS 桥接程序和 ESP8266 固件，Windows 客户端暂不更新。

## 用户体验

Mac 菜单栏增加「自动显示设置…」。设置窗口将自动项目分为两类：

- 事件型：Claude、Codex、审批提醒、音乐。用户设置是否启用；事件存在期间持续显示。
- 定时型：天气、股票、网速、名人名言。用户设置是否启用、出现间隔和单次显示时长。

关闭某个项目只表示它不参与自动显示，用户仍可在「屏幕显示」菜单和镜像窗口中手动固定到对应页面。所有项目均关闭时，设备显示空闲桌宠。

### 默认配置

| 项目 | 默认状态 | 间隔 | 显示时长 |
|---|---:|---:|---:|
| Claude 工作状态 | 关闭 | 事件触发 | 工作期间 |
| Codex 工作状态 | 开启 | 事件触发 | 工作期间 |
| 审批提醒 | 开启 | 事件触发 | 等待审批期间 |
| 音乐 | 开启 | 事件触发 | 播放期间 |
| 天气 | 开启 | 15 分钟 | 10 秒 |
| 名人名言 | 开启 | 30 分钟 | 12 秒 |
| 股票 | 关闭 | 15 分钟 | 10 秒 |
| 网速 | 关闭 | 10 分钟 | 10 秒 |

定时项目的间隔范围为 1–240 分钟，显示时长范围为 5–60 秒。Mac 保存设置前修正越界值，固件收到配置后再次防御性修正。

## 自动调度规则

自动模式使用以下优先级：

1. 已启用的审批提醒
2. 已启用且正在工作的 Codex 或 Claude
3. 已启用且正在播放的音乐
4. 到期的定时项目
5. 空闲桌宠

Claude 和 Codex 独立配置。Claude 默认关闭，未安装或未使用 Claude 的用户不会看到相关状态；Codex 和审批提醒也允许关闭。

定时项目采用公平轮换队列。项目到期后进入待显示队列；多个项目同时到期时，选择最久未显示的项目。一次展示结束后更新该项目的下次到期时间，不能由天气等单一项目持续抢占。高优先级事件出现时暂停当前定时页面；事件结束后，尚未完成的定时页面重新展示一个完整时长。

固定显示模式始终优先于自动配置，不运行自动调度。

## 名人名言功能

### 数据源

Mac 桥接程序通过两个联网来源获取名言：

- 中文：一言 API，使用正文、作者与出处字段。
- 英文：ZenQuotes，使用英文正文与作者字段。

中文和英文成功展示后交替选择。某一来源不可用时，另一来源可以继续工作；系统不要求严格的一中一英顺序。

### 内容处理

`QuoteMonitor` 负责：

- 异步请求及超时控制；
- 解析不同服务的响应并转换为统一模型；
- 过滤空正文、超出屏幕排版容量和最近已经显示过的内容；
- 作者缺失时使用出处，作者和出处均缺失时显示「佚名」；
- 保存最近一次中文、英文以及最近展示记录；
- 为设备生成固定尺寸的 RGB565 文字图层。

内容过长时优先重新请求，达到有限重试次数仍无合适内容则使用缓存，不截断作者署名。名言缓存写入 Mac 的 Application Support 目录，应用重启后仍然可用。

### 页面布局

240×240 页面包含：

- 顶部「每日一句」标题；
- 居中的多行名言正文；
- 右下方作者或出处；
- 底部语言标记与更新时间。

中文由 Mac 渲染成 RGB565 位图，避免在 ESP8266 中增加中文字库。英文也走相同渲染路径，以保证 Mac 镜像和设备布局一致。

菜单新增「换一句」，用于立即获取下一条内容。手动固定为「名人名言」时页面持续显示，并按名言自身的刷新周期更新；自动模式则按照用户配置的间隔和时长插播。

## 架构与数据流

### Mac 端

- `AutoDisplaySettings`：定义事件开关、定时项目参数、默认值、范围修正及持久化。
- `AutoDisplaySettingsWindow`：编辑配置，并在保存后触发设备同步。
- `QuoteMonitor`：获取、标准化、过滤、缓存并渲染名言。
- `HTTPServer` 路由：新增 `/quote` 与 `/quote/text.raw`；现有状态响应携带自动显示配置及修订号。
- `MenuBarController`：增加设置窗口、「名人名言」固定模式和「换一句」。
- `MirrorPopover`：增加名言模式按钮，并使用与设备相同的内容模型绘制预览。

配置以 `UserDefaults` 为唯一持久化来源。Mac 启动、配置保存或设备重新配对时，通过已有状态数据通道向设备同步最新配置。

### ESP8266 端

- 增加 `MODE_QUOTE`、名言状态模型、JSON 解析、RGB565 文字图层下载和页面绘制。
- 将天气专用的自动窗口逻辑替换为通用定时调度器。
- 保存最近同步的运行时配置；Mac 重新连接后覆盖。设备重启且尚未同步时使用固件默认配置。
- `/api/mode`、设备信息响应和设备网页模式选项增加 `quote`。

旧版 Mac 桥接不提供自动配置时，固件使用内置默认值。新版 Mac 连接旧固件时，设置仍可保存在 Mac，但界面应提示设备固件需要更新，而不是报告同步成功。

## 接口模型

名言 JSON 至少包含：

```json
{
  "text": "The only real mistake is the one from which we learn nothing.",
  "author": "Henry Ford",
  "language": "en",
  "updated_at": 1788013800,
  "text_rev": 4,
  "stale": false
}
```

自动配置使用稳定项目标识：`claude`、`codex`、`approval`、`music`、`weather`、`quote`、`stock`、`net`。事件项目只发送 `enabled`；定时项目发送 `enabled`、`interval_seconds` 和 `duration_seconds`。配置携带单调递增的 `revision`，固件只在修订号改变时重建调度状态。

## 容错

- 网络请求在后台执行，不阻塞菜单和 HTTP 服务。
- 请求超时、非成功状态码、错误 JSON 或空内容均视为本次刷新失败。
- 刷新失败时保留最近成功数据，并标记为过期；无缓存时跳过本次名言调度。
- RGB565 图层下载失败时不切换到空白名言页。
- Mac 断开时设备继续使用最近同步的自动配置；依赖 Mac 数据的页面无有效缓存时自动跳过。
- 配置字段缺失、类型错误或越界时使用该字段默认值，不丢弃整份配置。

## 测试与验收

### Mac 单元测试

- 配置默认值、保存读取、版本迁移和边界修正；
- 中英文响应解析、作者回退、超长过滤和最近内容去重；
- 中英文轮换及单一服务故障降级；
- 网络超时、错误响应和缓存恢复；
- 名言 RGB565 数据尺寸及修订号；
- 自动配置序列化字段与默认兼容行为。

### 固件原生逻辑测试

- Claude 关闭时不参与自动选择；
- 各事件优先级及项目独立开关；
- 多个定时项目同时到期时公平轮换；
- 高优先级事件打断后，定时页面获得完整展示时长；
- 全部关闭、无有效数据、配置越界及旧桥接缺字段；
- 固定模式不受自动配置影响。

### 集成验证

- Mac 镜像和真机固定/自动名言模式切换；
- 设置修改后设备及时采用新配置；
- 断网、Mac 重启和 ESP8266 重启后的缓存及默认行为；
- ESP8266 RAM、Flash 使用量和连续运行稳定性；
- Mac 与固件完整构建及现有回归测试。

## 不在本次范围内

- Windows 桥接程序；
- 用户自定义名言或导入本地名言库；
- 自动翻译英文名言；
- 按工作日、时段或地理位置设置规则；
- 在 ESP8266 上直接调用第三方名言接口。
